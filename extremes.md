- Finland anomaly: Project-GC reports the same cache (GCBEVAK "Friendship Austria - Finland", coordinates 48°12.502N 016°22.411E — Vienna, Austria) as both Finland's southernmost and westernmost cache. This is almost certainly a data-quality issue in the source database (likely a mis-tagged country), but it is reproduced here exactly as the tool displays it.
- Austria anomaly: GCBF36R "Friendship Finland - Austria" (located in Finland, near the Finnish north coast) is reported as Austria's northernmost, easternmost, and lowest cache — same mis-tagging pattern as the Finland note above.
- France: first attempt failed with a 504 gateway timeout; the retry succeeded.
- Slovakia: first attempt failed with a 504 gateway timeout; the retry succeeded.
- Kosovo is not present in the Project-GC country dropdown, so no data could be collected for it.
- Scope: all sovereign European states plus European territories present in the dropdown (Faroe Islands, Gibraltar, Guernsey, Isle of Man, Jersey, Sark, Svalbard and Jan Mayen Islands, Åland Islands) and transcontinental states commonly counted as European (Armenia, Azerbaijan, Cyprus, Georgia, Türkiye). Kazakhstan was excluded as predominantly Asian.
